Cloudflare Worker · Kurzbefehle · Apple Notes

Notizen-Relay

Claude liest und schreibt deine Apple Notes eigenständig — ohne Mac, ohne Kommandozeile. Eingerichtet wird alles im Safari auf dem iPad.

≈ 45 Min Einrichtung Kostenlos im Free-Tier Eine Datei zum Einfügen
Claude — MCP → Relay ← HTTPS — iPad-Kurzbefehl → Apple Notes

Claude erreicht dein iPad nicht — Connectors werden aus Anthropics Cloud aufgerufen. iPadOS wiederum lässt keinen Serverprozess zu. Der Relay ist der Treffpunkt dazwischen.

Wie es arbeitet

Lesen beantwortet der Relay sofort aus dem letzten Snapshot, den dein iPad hochgeladen hat. Schreiben legt er in eine Warteschlange, die dein iPad beim nächsten Sync abarbeitet.

Daraus folgt die wichtigste Eigenschaft dieses Aufbaus: Claude sieht deine Notizen mit dem Stand des letzten Syncs, nicht live. Neue Notizen entstehen mit Verzögerung. Das Werkzeug sync_status sagt jederzeit, wie alt der Stand ist.

Teil 1

Relay aufsetzen

Im Safari auf dem iPad. Keine Kreditkarte, keine eigene Domain, kein Terminal.

  1. Cloudflare-Konto anlegen

    dash.cloudflare.com öffnen und registrieren.

  2. Worker anlegen
    • Compute (Workers) → Create application → Start with Hello World!
    • Namen vergeben, z. B. notizen-relay → Deploy
    • Edit code öffnen, alles löschen, den Inhalt von relay/worker.js einfügen → Deploy

    Tipp: In GitHub bei worker.js auf Raw tippen, alles markieren, kopieren. Der Editor ist im Querformat deutlich handlicher.

  3. Speicher verbinden
    • Storage & Databases → KV → Create instance, Name z. B. notizen
    • Zurück zum Worker → Settings → Bindings → Add → KV namespace
    • Variable name: NOTES — genau so, der Worker sucht nach diesem Namen
    • KV namespace: notizen → Deploy
  4. Setup-Code setzen
    • Worker → Settings → Variables and Secrets → Add
    • Typ Secret, Name SETUP_CODE
    • Wert: etwas Langes und Zufälliges, z. B. korb-lampe-tiger-47-blau → Deploy

    Notiere dir den Code — du brauchst ihn gleich zweimal. Er schützt sowohl Claudes Anmeldung als auch den Zugang deines iPads.

  5. Läuft es?

    https://notizen-relay.<dein-name>.workers.dev/ im Safari aufrufen. Es muss „Notizen-Relay läuft" erscheinen.

    • Hinweis auf SETUP_CODE → Schritt 4 fehlt
    • Fehler zu NOTES → Variablenname der KV-Bindung aus Schritt 3 stimmt nicht
  6. Connector in Claude eintragen
    • In Safari claude.ai öffnen. Bei mobiler Ansicht: aA in der Adressleiste → Desktop-Website anfordern
    • Einstellungen → Connectors → Add custom connector
    • URL: https://notizen-relay.<dein-name>.workers.dev/mcp
    • Connect → Formular erscheint → Setup-Code eingeben → Verbinden

    Custom Connectors lassen sich nur auf claude.ai im Browser hinzufügen, nicht in der iPad-App. Danach synchronisiert Claude sie automatisch auf alle Geräte.

Teil 2

Sync-Kurzbefehl bauen

Ein einziger Kurzbefehl hält beide Richtungen am Laufen: Er holt Claudes Aufträge ab, führt sie in Apple Notes aus, und lädt danach den aktuellen Stand hoch.

Lege zuerst in Apple Notes einen Ordner „Claude" an — dort landet alles, was Claude neu anlegt. Dann in der Kurzbefehle-App auf + und den Kurzbefehl „Claude-Sync" nennen.

Zu den Aktionsnamen

Die deutsche Kurzbefehle-App übersetzt Aktionsnamen, und die Bezeichnungen wechseln zwischen iPadOS-Versionen. Unten steht jeweils deutsch und englisch — mit dem englischen Namen findest du die Aktion notfalls über die Suche im Aktionen-Katalog.

Teil A — Claudes Aufträge holen

  1. Inhalte von URL abrufen Get Contents of URL
    • URL: https://.../device/pull
    • Methode GET
    • Header X-Device-Token → dein Setup-Code
  2. Wörterbuchwert abrufen Get Dictionary Value
    • Schlüssel creates, aus dem Ergebnis von Schritt 1
  3. Mit jedem Objekt wiederholen Repeat with Each
    • Eingabe: Ergebnis aus Schritt 2
    • darin Wörterbuchwert abrufen → Schlüssel content
    • darin Notiz erstellen Create Note → Inhalt ist content, Ordner: Claude

    Der Relay liefert Titel und Text bereits zusammengesetzt, mit dem Titel als erster Zeile — genau daraus leitet Apple Notes den Notiznamen ab. Der Kurzbefehl muss hier nichts zusammenbauen.

  4. Wörterbuchwert abrufen Get Dictionary Value
    • Schlüssel appends, aus dem Ergebnis von Schritt 1
  5. Mit jedem Objekt wiederholen Repeat with Each
    • Eingabe: Ergebnis aus Schritt 4
    • Wörterbuchwert abrufen → title
    • Notizen suchen Find Notes → Filter Name enthält = title, Limit 1
    • Wörterbuchwert abrufen → text
    • An Notiz anhängen Append to Note → Notiz = Ergebnis von Notizen suchen, Text = text
Die häufigste Stolperstelle

An Notiz anhängen erwartet eine Notiz-Referenz, keinen Titel als Text. Ohne vorheriges Notizen suchen findet die Aktion ihr Ziel nicht.

Teil B — Aktuellen Stand hochladen

  1. Notizen suchen Find Notes
    • Sortieren nach Zuletzt geändert, absteigend
    • Limit 50 zum Einstieg — später auf 100 erhöhen
  2. Variable festlegen Set Variable
    • Name Snapshot, Wert leer lassen
  3. Mit jedem Objekt wiederholen Repeat with Each

    Darin eine Zu Variable hinzufügen-Aktion auf Snapshot, deren Wert eine Text-Aktion mit genau diesem Aufbau ist: 

    ###NOTE###
F: ⟨Ordner⟩
T: ⟨Name⟩
M: ⟨Zuletzt geändert⟩
B:
⟨Text⟩

    Die Marken ###NOTE###, F:, T:, M: und B: müssen exakt so stehen — der Relay zerlegt den Text daran.

  4. Text kombinieren Combine Text
    • Eingabe Snapshot, Trennzeichen Neue Zeile
  5. Inhalte von URL abrufen Get Contents of URL
    • URL https://.../device/push, Methode POST
    • Header X-Device-Token → dein Setup-Code
    • Anfragetext: Datei Request Body: File → Ergebnis aus Schritt 9

    Nicht „JSON" wählen — der Relay erwartet hier reinen Text.

  6. Mitteilung anzeigen Show Notification
    • Text: Ergebnis aus Schritt 10 — so siehst du sofort, was übertragen wurde
Magic Variables einsetzen

Die Werte in ⟨spitzen Klammern⟩ tippst du nicht ab. Tippe auf die Variablenleiste über der Tastatur und wähle das Wiederholungsobjekt.

Tippe die eingefügte Variable danach erneut an — dann lässt sich die Eigenschaft umstellen auf Ordner, Name, Zuletzt geändert oder Text.

Erster Lauf

Kurzbefehl starten. Beim ersten Mal fragt iPadOS nach Erlaubnis für Notizen und für den Netzwerkzugriff — beides erlauben. Die Mitteilung sollte so aussehen: 

{"ok":true,"notes":50,"jobsCompleted":0}

Danach in Claude fragen: „Wie ist der Sync-Status meiner Notizen?" — Claude sollte Zeitpunkt und Anzahl nennen.

Automatisch synchronisieren

Damit du nicht daran denken musst — die nützlichste Variante zuerst:

Beim Öffnen von Claude

  • Kurzbefehle → Automation → + → App
  • App Claude, Auslöser Wird geöffnet
  • Aktion Kurzbefehl ausführen → Claude-Sync
  • Sofort ausführen ein, Vor dem Ausführen fragen aus

Zusätzlich zeitgesteuert

Damit Claudes Aufträge auch ankommen, wenn du die App länger nicht öffnest: dieselbe Automation mit Auslöser Tageszeit, z. B. stündlich zwischen 8 und 22 Uhr.

Für den Alltag: Wenn Claude sagt „ist eingereiht", genügt ein Start des Kurzbefehls, damit es sofort passiert.

Was du wissen solltest

Deine Notizinhalte liegen im Snapshot bei Cloudflare

Das ist der Preis dieser Bauweise — anders kann Claude sie nicht lesen. Der Zugang hängt vollständig am Setup-Code; behandle ihn wie ein Passwort.

Wenn dir das zu weit geht: In Teil B, Schritt 8 die Zeile mit ⟨Text⟩ weglassen und B: stehen lassen. Claude kann dann Titel und Ordner sehen, suchen und schreiben — aber keine Inhalte lesen.

Bewusst weggelassen

  • Löschen und Überschreiben. Ein zeitversetzter Auftrag trifft auf einen veralteten Stand und könnte die falsche Notiz erwischen. Anlegen und Anhängen sind darin harmlos.
  • Live-Zugriff. Claude liest den Stand des letzten Syncs, nicht den aktuellen.
  • Vollständigkeit. Der Snapshot umfasst die zuletzt geänderten Notizen — ältere erscheinen nicht.

Kosten

Cloudflares Free-Tier reicht: 100 000 Worker-Anfragen und 100 000 KV-Lesevorgänge pro Tag. Ein persönlicher Notizabgleich liegt um Größenordnungen darunter.
