Apple Notes · Kurzbefehle · iPadOS

Notizen-Brücke fürs iPad

Fünf Kurzbefehle, die Claude und Apple Notes verbinden — über die Zwischenablage, ohne Server, ohne Mac, ohne laufende Kosten.

≈ 20 Min Einrichtung Keine App-Installation Nichts verlässt dein iPad
Prinzip Vorbereitung 1 Notiz an Claude 2 Index 3 Suche 4 Neue Notiz 5 Anhängen Zugriff Grenzen

Das Prinzip

iPadOS kennt kein AppleScript und lässt keinen Hintergrundprozess auf eine fremde App zugreifen. Die Kurzbefehle-App ist damit die einzige Schnittstelle zu Apple Notes — sie kann dafür fast alles, was ein Mac-Skript auch könnte.

Claude wiederum ruft Connectors aus Anthropics Cloud auf, nicht von deinem Gerät. Dein iPad wäre für einen Connector also gar nicht erreichbar. Deshalb übernimmt die Zwischenablage den Transport — und du gibst den Startschuss.

Lesen Apple Notes → Kurzbefehl → Zwischenablage → Claude
Schreiben Claude → Kopieren → Kurzbefehl → Apple Notes
Zu den Aktionsnamen

Die deutsche Kurzbefehle-App übersetzt Aktionsnamen, und die Bezeichnungen ändern sich zwischen iPadOS-Versionen gelegentlich. Unten steht darum jeweils deutsch und englisch — mit dem englischen Namen findest du die Aktion notfalls über die Suche im Aktionen-Katalog.

Vorbereitung

Lege in Apple Notes einen Ordner „Claude" an. Er dient als Eingang für alles, was Claude schreibt — so landet nichts versehentlich zwischen deinen eigenen Notizen.

Öffne dann die Kurzbefehle-App und tippe für jeden der fünf Kurzbefehle oben rechts auf +.

1

Notiz an Claude

Lesen

Wählt eine Notiz aus einer Liste und legt ihren Inhalt in die Zwischenablage.

  1. Notizen suchen Find Notes
    • Sortieren nach Zuletzt geändert, absteigend
    • Limit 25
    • Kein Filter — so erscheinen alle Notizen, zuletzt bearbeitete zuerst
  2. Aus Liste auswählen Choose from List
    • Eingabe: Ergebnis aus Schritt 1
    • Titel: Welche Notiz?
  3. Text Text 
    Notiz: ⟨Name⟩
Ordner: ⟨Ordner⟩
Geändert: ⟨Zuletzt geändert⟩

⟨Text⟩
  4. In die Zwischenablage kopieren Copy to Clipboard
  5. Mitteilung anzeigen Show Notification
    • Kopiert – in Claude einfügen
Magic Variables einsetzen

Die Werte in ⟨spitzen Klammern⟩ tippst du nicht ab. Tippe im Text-Feld auf die Variablenleiste über der Tastatur und wähle das Ergebnis von Aus Liste auswählen.

Tippe die eingefügte Variable danach erneut an — dann lässt sich die Eigenschaft umstellen auf Name, Text, Ordner oder Zuletzt geändert. So werden aus einer Notiz-Variable die vier Felder oben.

Nutzung

Kurzbefehl starten → Notiz wählen → zu Claude wechseln → einfügen.

2

Notiz-Index an Claude

Lesen

Gibt Claude den Überblick über deine Ordnerstruktur und alle Notiztitel — ohne die kompletten Inhalte. Claude kann dann gezielt sagen, welche Notiz es braucht.

  1. Notizen suchen Find Notes
    • Sortieren nach Zuletzt geändert, absteigend
    • Limit 200 — bei sehr vielen Notizen niedriger ansetzen
  2. Variable festlegen Set Variable
    • Name Index, Wert leer lassen
  3. Mit jedem Objekt wiederholen Repeat with Each
    • Eingabe: Ergebnis aus Schritt 1
    • darin Zu Variable hinzufügen → Index, Wert ist eine Text-Aktion: 
      ⟨Ordner⟩ | ⟨Name⟩
  4. Text kombinieren Combine Text
    • Eingabe Index, Trennzeichen Neue Zeile
  5. In die Zwischenablage kopieren Copy to Clipboard

Was bei Claude ankommt

Projekte | Sonntagsfrage Auswertung
Projekte | Fragebogen Entwurf
Privat | Einkaufsliste

Diese Umwegkonstruktion hat einen Grund: Kurzbefehle hat keine Aktion, die Ordner direkt auflistet. Der Ordnername ist aber eine Eigenschaft jeder Notiz — also leitet man die Struktur aus den Notizen ab.

3

Notizsuche an Claude

Lesen

Volltextsuche über alle Notizen; die Treffer landen gesammelt in der Zwischenablage.

  1. Nach Eingabe fragen Ask for Input
    • Typ Text, Frage Wonach suchen?
  2. Notizen suchen Find Notes
    • Filter Text enthält Body contains → Wert ist die Eingabe aus Schritt 1
    • Limit 10
  3. Variable festlegen Set Variable
    • Name Treffer, leer
  4. Mit jedem Objekt wiederholen Repeat with Each
    • darin Zu Variable hinzufügen → Treffer: 
      ### ⟨Name⟩ (⟨Ordner⟩)
⟨Text⟩
  5. Text kombinieren Combine Text
    • Trennzeichen Neue Zeile
  6. In die Zwischenablage kopieren Copy to Clipboard
Falls der Filter die Eingabe nicht annimmt

Auf das Filterfeld tippen und die Variable aus der Leiste über der Tastatur wählen. Filterwerte akzeptieren Variablen — die Ordner-Auswahl dagegen nicht, die bleibt eine feste Auswahl.

4

Claude → neue Notiz

Schreiben

Nimmt den in Claude kopierten Text und legt daraus eine neue Notiz an.

  1. Zwischenablage abrufen Get Clipboard
  2. Notiz erstellen Create Note
    • Inhalt: Ergebnis aus Schritt 1
    • Ordner: Claude — das Feld antippen und den Ordner wählen
  3. Notiz anzeigen Show Note
    • Eingabe: die erstellte Notiz
Zwei Eigenheiten von Apple Notes

Der Titel entsteht aus der ersten Zeile des Inhalts. Bitte Claude also, mit einer sauberen Titelzeile zu beginnen — sonst heißt die Notiz wie der erste Halbsatz.

Markdown wird nicht gerendert: **fett** bleibt als Sternchen stehen. Sag Claude für diesen Weg am besten „ohne Markdown, nur Klartext mit Bindestrich-Listen".

5

Claude → an Notiz anhängen

Ändern

Hängt den kopierten Text unten an eine bestehende Notiz an.

  1. Zwischenablage abrufen Get Clipboard
  2. Notizen suchen Find Notes
    • Sortieren nach Zuletzt geändert, Limit 25
  3. Aus Liste auswählen Choose from List
    • Titel An welche Notiz anhängen?
  4. An Notiz anhängen Append to Note
    • Notiz: Ergebnis aus Schritt 3 (Magic Variable)
    • Text: Ergebnis aus Schritt 1
  5. Mitteilung anzeigen Show Notification
    • Angehängt
Warum erst suchen, dann anhängen

An Notiz anhängen erwartet eine Notiz-Referenz, keinen Titel als Text. Ohne vorheriges Notizen suchen findet die Aktion ihr Ziel nicht — das ist die häufigste Stolperstelle bei diesem Kurzbefehl.

Schneller Zugriff auf dem iPad

Damit die Kurzbefehle im Alltag nicht stören, lohnt sich mindestens eine dieser Optionen:

  • Home-Bildschirm: im Kurzbefehl auf ⓘ → Zum Home-Bildschirm hinzufügen
  • Kontrollzentrum: Einstellungen → Kontrollzentrum → Kurzbefehle hinzufügen
  • Tastaturkürzel (mit Magic Keyboard): in der Kurzbefehle-App auf ⓘ → Tastaturkurzbefehl — der schnellste Weg, wenn Claude im Split View liegt
  • Split View: Claude links, Kurzbefehle rechts — dann sind Kopieren und Einfügen ein Fingertipp ohne App-Wechsel

Was dieser Weg nicht kann

Ehrlich vorab, damit dich später nichts überrascht:

  • Claude arbeitet nicht von allein. Jeder Austausch braucht deinen Tipp. Automatisches Lesen im Hintergrund ist auf iPadOS ohne gehosteten Relay nicht möglich.
  • Kein Ersetzen von Inhalten. Kurzbefehle kann anhängen und erstellen, aber den Text einer bestehenden Notiz nicht überschreiben. Workaround: neue Notiz anlegen, alte löschen.
  • Kein Markdown-Rendering in Apple Notes über diesen Weg.
  • Passwortgeschützte Notizen liefern über Notizen suchen keinen Inhalt.
  • Lange Notizen können Zwischenablage und Kontextfenster sprengen — dafür ist Kurzbefehl 2 gedacht: erst die Struktur zeigen, dann gezielt eine Notiz holen.

Wenn du später mehr willst

Sobald ein Mac dazukommt, ist der MCP-Server im Repository der bequemere Weg: Claude liest und schreibt dann ohne dein Zutun, und die Kurzbefehle können daneben bestehen bleiben.

Der Mittelweg ohne Mac wäre ein gehosteter Relay-Server plus ein Kurzbefehl, der regelmäßig Aufträge abholt. Das kostet Einrichtung und ein Hosting-Konto — sag Bescheid, wenn es so weit ist.
